## Overview
HyperDrift is a top-down 2D Vehicular combat roguelite inspired by vampire survivor style mechanics, built in Unity. Players control a high speed vehicle, and drift in precise loops to eliminate huge swarms of enemy robots.

## Key Features
- Physics based movement and responsive vehicle control
- Roguelite car upgrades
- Fast paced combat based on movement
- 3 types of enemies along with a Mini Boss
- Consistent visual feedback and gameplay polish

## My contribution
I was responsible for the entire programming and technical implementation of the game, including all gameplay systems and mechanics. My partner focused on game design, developing the core idea, and playtesting to refine the game.
